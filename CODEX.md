Файл `sources/Cortex Prime - Game Handbook [08-13-2020].pdf` добавлен в приватный репозиторий (коммит `00d69d8`). Перевод не начат. Первичные результаты: `translation/source-analysis.md`, `translation/chapters.md`, `translation/source-inventory.json`. На сайте пока страницы-заготовки.

В разговоре о выборе системы для Хисуи пользователь уточнил: планируются два игровых персонажа; имплантов немного; Fate даёт игрокам слишком много прав. Cortex обсуждался как кандидат, но окончательный выбор системы и конкретной сборки не утверждён. Эти предпочтения не дают права менять правила при переводе.

## Что уже сделано

VitePress **1.6.4**, Vue 3, точные зависимости в `package-lock.json`. Русские меню, локальный поиск, светлая/тёмная тема, мобильная навигация, оглавление страницы и штатные переходы на соседние страницы.

Дополнительно реализованы закладки на текущий заголовок и продолжение чтения. Сейчас это местное хранилище браузера, без аккаунтов, сервера и синхронизации устройств.

Основные файлы:

| Путь | Назначение |
| --- | --- |
| `book/.vitepress/config.mts` | Конфигурация сайта, меню, поиск, переводы интерфейса, базовый URL |

| `book/.vitepress/theme/style.css` | Оформление и размеры элементов для телефона |

## Запуск и проверка

PowerShell из корня проекта (на Windows использовать `.cmd`, если политика PowerShell мешает запуску npm):

```powershell
npm.cmd ci
npm.cmd run build
npm.cmd run preview -- --port 4173
```

Разработка: `npm.cmd run dev`. Для предполагаемого размещения в подпапке `/cortex-ru/`:

```powershell
$env:SITE_BASE = '/cortex-ru/'
npm.cmd run build
```

Для локальной сборки в корне сайта убрать эту переменную. Не считать localhost публичным адресом: с телефона `127.0.0.1` указывает на сам телефон.

В момент передачи preview был запущен на http://127.0.0.1:4173/ в машине исходного агента. Процесс может завершиться; повторный запуск делать после проверки занятости порта. Исторический инструментальный session ID не нужен для продолжения на другом агенте.

### Подтверждённые проверки

- `npm run build` завершился успешно; CI для `10f013b` и `f24f1c4` тоже прошёл.
- В Chromium через Playwright: `/about` → «В закладки» → `/reader` → перезагрузка. После перезагрузки остались ссылка «О переводе», кнопка удаления и ссылка продолжения чтения.
- В консоли наблюдался 404 для `/favicon.ico`; функциональная ошибка не выявлена. Собственного favicon пока нет.

### Что пока не проверено полностью

- Длинные настоящие главы, сложные таблицы, изображения и перекрёстные ссылки: оригинал получен, но эти элементы ещё не перенесены на сайт.
- Полный сценарий на реальном телефоне и Safari; удаление закладки и отказ localStorage требуют отдельной проверки при следующей доработке.
- Экспорт/импорт закладок, синхронизация и офлайн-режим не реализованы.
- Небольшая часть стандартных accessibility-подписей VitePress может остаться английской.

## С чего продолжить

1. Прочитать `AGENTS.md`, этот файл и `translation/character-sheet.md`; проверить `git status`, свежий лог и наличие локального PDF.
2. Открыть полученный оригинал в `sources/` и прочитать первичный анализ. Не заменять его случайным интернет-изданием.
3. Проверить подготовленную карту `translation/chapters.md` по страницам. Учесть колонки, графические символы и смещение пагинации +4; подробности в анализе.
4. Определить начальные термины по тексту, заполнить глоссарий и переводить последовательно с указанием страниц и статуса проверки.
5. Добавлять реальные главы в меню, сохранять постоянные URL, проверять сборку и работу переходов.
6. К PDF-листу вернуться после отдельного указания пользователя. Сначала исследовать исходные поля и согласовать конкретные улучшения.

Обновлять этот снимок при передаче обратно: что переведено, что сверено, какие решения приняты, какие вопросы остались и какие коммиты отправлены. Не оставлять статус «готово» без проверки.
