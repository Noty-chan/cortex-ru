# Короткое поручение следующему агенту

Можно передать следующий текст новому агенту вместе с доступом к репозиторию:

> Продолжи проект русской книги-сайта Cortex в `D:\Files\Notes\Cortex-RU` (приватный репозиторий https://github.com/Noty-chan/cortex-ru). Сначала прочитай `AGENTS.md` и `CODEX.md`, проверь Git и доступные исходники. VitePress-читалка с закладками и поиском уже собрана; её не нужно создавать заново. Английская книга уже получена и добавлена в приватный репозиторий: `sources/Cortex Prime - Game Handbook [08-13-2020].pdf` (256 страниц). Перед переводом прочитай `translation/source-analysis.md` и подготовленную карту `translation/chapters.md`; полный перевод ещё не начат. Русский интерактивный лист скачан локально в `sources/`; его улучшения пользователь отложил. Не публикуй приватный перевод автоматически и не смешивай перевод с домашними правилами Хисуи. Работай по новым указаниям пользователя, фиксируй прогресс, термины, проверки и обновляй `CODEX.md` для возврата работы.

Если агент работает на другой машине, Русский PDF-лист из `sources/` нужно передать отдельно: он исключён из Git. Английская книга уже отслеживается в приватном Git. Ссылка на PDF сохранена в `translation/character-sheet.md`.

Доступ к приватному репозиторию даёт пользователь. Подготовка передачи не означает, что другому агенту уже отправлено сообщение или создан отдельный чат.
