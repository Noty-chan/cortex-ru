## Окончательное правило развития TRACE

1. Собрать базовые2d6 и по одной кости наивысшего за текущую встречу стресса каждого вида. При4–5 видах стресса использовать стрессовые кости **вместо** базовых2d6.
2. Добавить сохранённые неиспользованные кости любого происхождения; оставить пять крупнейших, если их больше пяти.
3. Выбрать одну или несколько развиваемых черт и разделить кости между ними. Каждая выбранная черта получает одну попытку за встречу; каждая кость участвует только в одной попытке.
4. При наличии стресса за текущую встречу итог игрока — два выбранных результата, либо один при броске одной кости. Если текущего стресса не было, итог — **один наибольший выпавший результат**, сколько бы сохранённых костей ни участвовало. Противодействие складывает два результата обычным образом.
5. В этих проверках у **обеих сторон единицы — обычные числовые результаты**. Они не активируются как зацепки, не создают осложнений и не вызывают особого провала; обычная неудача всё равно наступает, если итог не превысил сложность. PP не применяются, кость эффекта не нужна. Это частное исключение проверок развития TRACE.
6. Все использованные кости тратятся независимо от исхода. Неиспользованные сохраняются. За каждую неудачную попытку можно сохранить новуюd6 на следующую встречу; её нельзя тратить на повторные попытки в эту же встречу.

Выбор наибольшего результата — **осознанная балансная редакция**, одобренная основным агентом в рамках поручения пользователя; это не заявление об обнаруженной официальной поправке. Отклонён мой предварительный вариант двух отдельных режимов для свежей базы и накопленных костей: он требовал больше процедур, а единая формула проще и не требует различать происхождение костей.

## Точный расчёт вероятностей CP-027

Проверены все равновероятные комбинации, без моделирования случайной выборкой. Победа требует строго большего итога; равенство — неудача. У противодействия обычный итог двух костей. Единицы у обеих сторон считаются числами согласно принятому выше исключению. PP, эффекты и дополнительные способности не используются.

| Пул и сложность | Буквальный lowest: один наименьший | Выбранный highest: один наибольший | Полный обычный итог: два наибольших |
| --- | ---: | ---: | ---: |
|5d6 против2d6, изменение ресурса|0,5751% (1610/279936)|**22,0300% (61670/279936)**|79,1017% (221434/279936)|
|d10+3d6 против2d10, повышение роли|0,4880% (1054/216000)|**14,4046% (31114/216000)**|46,1736% (99735/216000)|

Всего279936 комбинаций в первом сравнении и216000 во втором. Для обычного двухкостного итога брались два крупнейших результата: при росте кость эффекта не нужна, поэтому сохранение меньшего итога ради эффекта бессмысленно.

**Что это показывает.** При буквальном lowest добавленная кость может ухудшить пул. Highest монотонен: ещё одна кость не уменьшает максимум, хотя предел5 и обязательное отсечение крупнейших применяются до броска. По двум проверенным конфигурациям спокойная встреча всё ещё заметно слабее полноценной попытки со стрессом:22,03% против79,10% и14,40% против46,17%. При этом накопления больше не превращают практически возможный рост в полупроцентную случайность. Это локальная оценка конкретных бросков, а не доказательство общего баланса всех кампаний.

### Разделение пула и возможное накопление

Пятьd6 можно разделить на пять разных ресурсных целей по однойd6. У отдельной попыткиd6 против2d6 шанс20/216 =9,2593%; вероятность хотя бы одного успеха за пять независимых попыток —38,4807%, ожидаемое число улучшений —0,46296. Это выгоднее одной спокойной попытки highest22,03%, но такой выбор деления уже предусмотрен модулем. Для стрессовой встречи обычная единая попытка5d6 даёт79,10%, поэтому стресс сохраняет сильное преимущество. Одну и ту же черту нельзя пять раз перебрасывать этими костями: одна цель — одна попытка за встречу.

Сохранение базовых костей может постепенно наполнить пул спокойными встречами. Это не бесконечный рост: в пуле максимум5; при попытке кости тратятся, успешная попытка не возвращает их, а компенсационнаяd6 за неудачу появляется только на следующую встречу. Дробление на неудачные попытки не позволяет тут же зациклить броски. Даже максимально накопленный5d6 остаётся одночисловым итогом в спокойной встрече. Для ресурса такой итог никогда не выше6, тогда как противодействие2d6 может дать12.

Предметное обоснование нового ресурса или повышения остаётся частью завершающей сцены; расчёт не отменяет необходимость выбрать существующую игровую черту/новый ресурс. Бесплатные дубли меток и повышение оценки Карлоса ради двух тегов отдельно исключены решением026.

### Воспроизводимый расчёт

Код выполнен bundled Python через PowerShell; ниже достаточно стандартной библиотеки. Все комбинации перечисляются ровно один раз.

```python
from collections import Counter
from itertools import product

def distribution(sizes, mode):
    counts = Counter()
    for values in product(*(range(1, n + 1) for n in sizes)):
        values = sorted(values)
        result = (values[0] if mode == "low" else
                  values[-1] if mode == "high" else
                  sum(values[-2:]))
        counts[result] += 1
    return counts

for player, opponent in [([6] * 5, [6, 6]),
                         ([10, 6, 6, 6], [10, 10])]:
    opposition = distribution(opponent, "two")
    for mode in ("low", "high", "two"):
        outcomes = distribution(player, mode)
        wins = sum(a * b for x, a in outcomes.items()
                   for y, b in opposition.items() if x > y)
        total = sum(outcomes.values()) * sum(opposition.values())
        print(player, opponent, mode, wins, total, 100 * wins / total)
```

При предварительной проверке также просчитан вариант, где единицы исключались бы из обоих пулов. Он не принят: явное правило единиц выше устраняет эту неоднозначность. Для полноты чувствительности highest давал27,5738% и16,3968%, обычный итог79,5961% и47,2634%; качественное сопоставление не менялось. Эти значения не являются правилами второй действующей версии.
