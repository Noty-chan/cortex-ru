# Cortex на русском

Это отдельный проект перевода предоставленной пользователем английской книги и читательского сайта. Хисуя находится в другом репозитории.

Перед продолжением работы прочитать `CODEX.md` — там снимок состояния, проверки, локальные исходники и отложенные задачи. `HANDOFF.md` содержит короткое поручение для передачи. После существенного этапа обновлять рабочий контекст, не выдавая запланированное за выполненное.

## Перевод

- До получения книги не писать перевод по памяти и не подменять его пересказом. Не смешивать Cortex Prime, Cortex Classic, Cortex Plus и разные издания.
- При получении книги определить название, издание, выходные данные и разницу между номерами страниц PDF и печатной нумерацией. Составить карту глав в `translation/chapters.md`.
- Переводить с сохранением смысла, примеров, чисел, таблиц, условий, исключений и перекрёстных ссылок. Изменения правил и советы ведущему не вставлять в авторский текст.
- Термины согласовывать с `book/glossary.md`. Спорные варианты отмечать в `translation/questions.md`, решения фиксировать в `translation/decisions.md`.
- Готовность отмечать честно: черновик / сверено с оригиналом / вычитано. У каждой главы указывать источник и страницы.
- Крупные главы делить по содержательным разделам; сохранять последовательное чтение и постоянные URL. Не менять идентификаторы заголовков без необходимости: на них ссылаются закладки.

## Сайт и публикация

- Основа — VitePress; перевод хранится в Markdown в `book/chapters/`. Меню настраивается в `book/.vitepress/config.mts`.
- После изменений интерфейса проверять `npm run build`. Для закладок проверять сохранение после перезагрузки; не обещать синхронизацию между устройствами: данные хранятся в браузере.
- 17 октября 2026 пользователь прямо поручил открыть репозиторий и опубликовать читалку на GitHub Pages. Это актуальное разрешение заменяет прежнее ограничение приватности. Поддерживать публикацию через `.github/workflows/deploy.yml`, `SITE_BASE=/cortex-ru/`. Соседнюю Хисую не затрагивать.
- Предоставленный английский оригинал хранится в `sources/` и по прямому указанию пользователя добавлен в приватный Git. Русский интерактивный лист тоже добавлен в приватный Git по прямому указанию пользователя; первая доработка описана в `translation/character-sheet.md`.
