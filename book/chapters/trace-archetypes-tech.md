# SWAT и киберпреступность {#tactical-and-tech-archetypes}

> Источник: *Cortex Prime Game Handbook*, Cam Banks, Fandom, 2020, с.171 (PDF175). Статус: сверено с оригиналом; независимая проверка пройдена, литературная вычитка впереди.

## Сотрудник SWAT {#swat}

Месяцы суровой подготовки к полицейским операциям в условиях сильного стресса и оттачивание навыков с лучшими из лучших оставили мышечную память, рождённую синяками. Вы уже не уверены, где начинаются границы вашей личности и заканчивается потрёпанный полицейский строй.

![Сотрудник SWAT](/images/original/pdf-175-art-01.webp)

**Принадлежности:** Один d6; Вдвоём d8; Отрядом d10.

| Роль | Кость |
| --- | --- |
| Криминалистика | d4 |
| Расследование | d6 |
| Право | d8 |
| Медицина | d6 |
| Психология | d6 |
| Тактика | d10 |
| Технологии | d8 |

**Отличительные черты:** Я здесь просто работаю (I Just Work Here); Полегче (Easy Does It).

| Ресурс | Метки | Кости |
| --- | --- | --- |
| Штаб TRACE | Право, Тактика, Технологии | 2d10 |
| Департамент шерифа округа Сан-Нарсисо | Криминалистика, Тактика | 2d8 |
| Ирландский бар Hair of the Dog | Психология | 2d6 |
| Региональная больница Тристеро | Медицина | 2d6 |

**Талант SWAT: Оценка угрозы (Threat Assessment).** При успешной проверке **Тактики** против цели GM должен назвать её черту с наибольшей оценкой. Потратьте **1 PP**, и GM также назовёт черту с наименьшей оценкой.

## Специалист по киберпреступности (Cybercrime Specialist) {#cybercrime-specialist}

В сети не спрятать человеческое невежество, злобу и отчаяние. Каждый день вы видите, что пелена анонимности делает с худшими представителями общества. Как бы вы ни любили технологии, ненависть, которую они питают в людях, неизменно вас бесит.

![Специалист по киберпреступности](/images/original/pdf-175-art-02.webp)

**Принадлежности:** Один d10; Вдвоём d6; Отрядом d8.

| Роль | Кость |
| --- | --- |
| Криминалистика | d8 |
| Расследование | d8 |
| Право | d6 |
| Медицина | d6 |
| Психология | d6 |
| Тактика | d4 |
| Технологии | d10 |

**Отличительные черты:** Я вижу на много миль (I Can See for Miles and Miles); Призрак в машине (Ghost in the Machine).

| Ресурс | Метки | Кости |
| --- | --- | --- |
| Штаб TRACE | Криминалистика, Право, Технологии | 2d10 |
| Синдикат Rogue Link | Расследование, Технологии | 2d8 |
| Управление шерифа округа Сан-Нарсисо | Право | 2d6 |
| Humentum | Технологии | 2d6 |

**Талант специалиста: Войдёшь уже в систему или будешь свистеть «Дикси»? (Are You Going to Log In or Whistle Dixie?).** Бросая кость **Технологий** в проверке или состязании против другого компьютерного эксперта, добавьте **d8** в пул. За **1 PP** удвойте эту добавку до **2d8**.
