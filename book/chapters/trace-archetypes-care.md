# Парамедик и переговорщик {#care-archetypes}

> Источник: *Cortex Prime Game Handbook*, Cam Banks, Fandom, 2020, с.170 (PDF174). Статус: сверено с оригиналом; независимая проверка пройдена, литературная вычитка впереди.

## Парамедик (Emergency Medical Technician) {#emt}

Долгие бессонные недели, вождение скорой, доставка пациентов в приёмное отделение и совместная работа с полицией всё равно не подготовили вас к TRACE. Вы парамедик команды, но также главный связной со всеми экстренными службами: вы говорите на их языке. Людей, которым нужны ваши умения, всегда хватает.

![Парамедик](/images/original/pdf-174-art-01.webp)

**Принадлежности:** Один d8; Вдвоём d8; Отрядом d8.

| Роль | Кость |
| --- | --- |
| Криминалистика | d6 |
| Расследование | d4 |
| Право | d6 |
| Медицина | d10 |
| Психология | d6 |
| Тактика | d8 |
| Технологии | d8 |

**Отличительные черты:** Ищи тех, кто помогает (Look for the Helpers); Лучшее время — сейчас (No Time Like the Present).

| Ресурс | Метки | Кости |
| --- | --- | --- |
| Региональная больница Тристеро (Tristero) | Медицина, Психология, Технологии | 2d10 |
| Штаб TRACE | Право, Тактика | 2d8 |
| Ночной клуб Four Seasons | Расследование | 2d6 |
| SimpyriMed | Медицина | 2d6 |

**Талант парамедика: Взять на себя (Take It On).** Когда уделяете время помощи другому персонажу, можете получить **стресс d6** выбранного вида или повысить его, чтобы понизить один стресс этого персонажа. Потратьте **1 PP**, чтобы повторить.

## Кризисный переговорщик (Crisis Negotiator) {#crisis-negotiator}

Вы начинали добровольным консультантом, а теперь зарабатываете тем, что уговариваете людей спуститься с крыш. У вас есть мегафон, голос, вызывающий доверие, и ясное представление о пути к деэскалации. Вы снимаете накал горячей сцены, перенаправляете гнев граждан и контролируете кризис.

![Кризисный переговорщик](/images/original/pdf-174-art-02.webp)

**Принадлежности:** Один d10; Вдвоём d6; Отрядом d8.

| Роль | Кость |
| --- | --- |
| Криминалистика | d4 |
| Расследование | d8 |
| Право | d6 |
| Медицина | d8 |
| Психология | d10 |
| Тактика | d6 |
| Технологии | d6 |

**Отличительные черты:** Теперь делаем по-моему (Now We Do It My Way); Слушай мой голос (Listen to the Sound of My Voice).

| Ресурс | Метки | Кости |
| --- | --- | --- |
| Штаб TRACE | Расследование, Тактика, Технологии | 2d10 |
| Консультационная служба Quiet Path | Медицина, Психология | 2d8 |
| Управление шерифа Сан-Нарсисо | Право | 2d6 |
| Мэрия | Расследование | 2d6 |

**Талант переговорщика: Море спокойствия (Sea of Calm).** Если сотрудник отряда проиграл проверку или состязание в пределах слышимости или поддерживает с вами радиосвязь, можете дать ему свою кость **Отрядом** на следующий бросок без дополнительных последствий. Потратьте **1 PP**, чтобы устранить одно из его осложнений, если есть.
