## Поля и подписи оригинала {#labels}

**Имя; Прошлое; Описание. Лист персонажа. XP.**

**Роли:** Воин, Жрец, Разведчик, Другая роль. Для каждой шкала d4, d6, d8, d10, d12.

**Атрибуты:** Мужество, Грация, Хитрость, Разум, Выносливость. Для каждого шкала d4–d12, отдельная шкала **Стресс** d4–d12 и отметка **Выделенный атрибут**.

**Отличительная черта эндарха d8:** строка названия, три поля **Сила 1, Сила 2, Сила 3**, каждое d8. В области **Спецэффекты эндарха**:

- **Помеха:** получите 1 PP, когда заменяете d8 своей отличительной черты эндарха на d4.
- Три пустые строки спецэффектов.
- **Призыв:** отключите эту отличительную черту эндарха, чтобы призвать своего эйдолона в следующий ход.

**Призванный эйдолон:**

| Поле | Преднапечатанные значения |
| --- | --- |
| Базовая черта | 2d10 **или** 2d4 |
| Масштаб | d8 |
| Силы | Три поля d12 |
| Выделенные атрибуты | Два поля d12 |

**Отличительная черта роли d8** и **Свободная отличительная черта d8:** по полю названия и одинаковому спецэффекту **Помеха: получите 1 PP, когда заменяете d8 своей отличительной черты на d4**.

**Совет оригинала:** «Для лучшего результата пользуйтесь карандашом».
