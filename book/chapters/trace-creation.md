# Архетипы TRACE {#trace-archetypes}

> Источник: *Cortex Prime Game Handbook*, Cam Banks, Fandom, 2020, с.168 (PDF172), введение к архетипам. Статус: сверено с оригиналом; независимая проверка пройдена, литературная вычитка впереди.

Архетипы позволяют быстро начать игру. В каждом заранее заданы **две отличительные черты, один талант, кости принадлежностей, роли и ресурсы**. При завершении листа их можно немного настроить.

1. **Выберите архетип:** есть семь основных вариантов.
2. **Придумайте третью отличительную черту:** нечто, отличающее вашего персонажа от похожих на него.
3. **Выберите второй талант** из общего списка. Другой вариант: замените талант архетипа и возьмите **два общих таланта**.
4. **Выберите имя и другие определяющие подробности прошлого.**

Каждый архетип получает **один ресурс 2d10, один 2d8 и два ресурса по 2d6**. При желании можно заменить конкретные ресурсы, используя предложения в описаниях районов Кортес-Сити.
