# Пирамида навыков и специализации {#skill-mods}

> Источник: *Cortex Prime Game Handbook*, Cam Banks, Fandom, 2020, с. 59 (PDF 63). Статус: сверено с оригиналом; независимая проверка пройдена, литературная вычитка впереди.

## Модификация: пирамида навыков {#skill-pyramid}

Чтобы игроки не слишком быстро доводили навыки или другие черты до максимума, можно потребовать соблюдать **пирамиду навыков** (skill pyramid). Для навыка **d10** нужно хотя бы **два навыка d8 и три d6**. Для **d12** — хотя бы **два d10, три d8 и четыре d6**. Ради поддержания пирамиды может понадобиться сначала повысить навык d4, прежде чем повышать другие, более крупные кости, пока пирамида не восстановится. Поскольку навыки начинаются с **d4**, обязательного количества навыков d4 в пирамиде нет.

![Две пирамиды навыков: требования для d10 и d12](/images/diagrams/skill-pyramid-dark.svg)

Верхнюю оценку можно получить, лишь достигнув нужного количества навыков заданных оценок под чертой. Затем навык со второго уровня можно поднять на вершину.

| Желаемая вершина | Требуемое основание |
| --- | --- |
| d10 | Два навыка d8, три навыка d6 |
| d12 | Два навыка d10, три навыка d8, четыре навыка d6 |

Если вместе с этой модификацией используются выделенные черты отличительных черт или другие бонусные повышения навыков, после применения бонусов игроки должны «достроить» пирамиду, устранив перекосы.

## Модификация: специализации {#specialties}

**Специализация** — узкая область внутри навыка. Она даёт дополнительную **d6** в любой проверке или состязании, относящихся к этой области и использующих связанный навык. Установленного списка нет; примеры: **Захваты (Grappling), Соблазнение (Seduction), Винтовки (Rifles), Карманные кражи (Pickpocket)**.

### Специализация: огнестрельное оружие {#guns-specialty}

| Навык | Действие | Дополнительная d6? |
| --- | --- | --- |
| Стрелять d12 | Выстрелить из охотничьей винтовки | Да |
| Стрелять d12 | Выстрелить из лука | Нет |
| Чинить d8 | Починить пушку | Да |
| Чинить d8 | Починить генератор | Нет |
| Знать d10 | Определить калибр пули | Да |
| Знать d10 | Определить автора картины | Нет |

Если использовать специализации без навыков, они заменяют навыки, но не действуют по умолчанию. Они начинаются с **d6** и могут повышаться до **d12**; если у вас нет специализации, нет и её оценки. Подробнее — ниже, в разделе «Без навыков, только специализации».

## Модификация: многоуровневые специализации {#multi-level-specialties}

Специализации начинаются с **d6**, но при создании или через опыт могут повышаться до нескольких костей или более крупных костей. Обычно ступени такие:

| Уровень | Варианты оценки |
| --- | --- |
| Подготовленный (Trained) | d6 |
| Эксперт (Expert) | d8 **или** 2d6 |
| Мастер (Master) | d10 **или** 2d8 **или** 3d6 |
| Грандмастер (Grandmaster) | d12 **или** 2d10 **или** 3d8 **или** 4d6 |

## Модификация: без навыков, только специализации {#no-skills-just-specialties}

В игре Cortex Prime без навыков как набора черт специализации могут быть самостоятельными чертами. С этой модификацией они оцениваются **от d8 до d12**, а не фиксированной d6. В отличие от навыков, общего уровня по умолчанию нет: отсутствие специализации означает, что соответствующие действия не имеют особой важности или значимости для персонажа.

> Без специализации «Карманные кражи» Мудрец Тины по-прежнему может незаметно стащить ключ; просто не получает за это дополнительную кость сверх других подходящих черт.

Без навыков полезно подготовить общий список специализаций, сохраняющий тематику сеттинга. Например, **Компьютеры (Computers), Космические корабли (Spacecraft), Лазерное оружие (Laser Weapons)** сообщают игрокам, что всё это есть в мире.

::: info Примечание к оригиналу
Выше на той же странице специализации без навыков начинаются с d6; здесь указан диапазон d8–d12. Обе формулировки сохранены, различие пока не разрешено: [CP-015](../source-issues#cp-015).
:::

## Модификация: разделение навыка и специализации {#skill-specialty-split}

Общие навыки персонажа оцениваются как **d4 — без подготовки** или **d6 — умелый**, а для более высоких оценок нужна специализация. **d8 — эксперт, d10 — мастер и d12 — грандмастер** доступны только специализациям навыка. У персонажа может быть несколько специализаций с разными оценками.

> Мэри Роуз ведёт игру, где общий навык **Водить (Drive)** не выше **d6**, а для **d8** и выше нужна специализация вроде **Мотоциклов (Motorcycles)**. Герой Адама может получить **Водить d6 (Скоростные катера (Speed Boat) d8, Мотоциклы d10, Дрифт-кары (Drift Cars) d10)**.

Вы **не добавляете в пул и навык, и специализацию**. Специализация заменяет кость навыка. Сам навык используется во всех проверках и состязаниях, к которым специализации не подходят.

Эта модификация воспроизводит работу навыков Classic Cortex и подходит, если вы хотите много узких навыков с высокими оценками.
