# Глоссарий

[Полный авторский словарь и указатель с.228–237](./chapters/book-index-a-d) переведён отдельно.

Рабочая терминология по переведённым разделам *Cortex Prime Game Handbook* (2020). Это редакторские варианты первого прохода, не утверждённые пользователем. Определения уточняются по книге; переводческие вопросы отделены от реестра ошибок оригинала.
