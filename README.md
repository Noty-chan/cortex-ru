# Cortex на русском

Рабочее пространство перевода книги Cortex и удобная электронная книга на VitePress.

Первый перевод Cortex Prime Game Handbook (Cam Banks, Fandom, 2020) завершён: введение, шесть глав, авторский словарь/указатель, благодарности, приложения и выходные сведения. Все блоки прошли независимую проверку; общая литературная, терминологическая и визуальная вычитка продолжается. Статические бланки и схемы воспроизведены на тёмном фоне.

Читалка: https://noty-chan.github.io/cortex-ru/

По прямому поручению пользователя от17.10.2026 репозиторий открывается и читалка публикуется на GitHub Pages. Каждое обновление main запускает `.github/workflows/deploy.yml`, собирающий только `book/` с `SITE_BASE=/cortex-ru/`.

Карта: `translation/chapters.md`; проверки: `translation/review-log.md`; неясности оригинала: `translation/source-issues.md`; продолжение: `HANDOFF.md`.

## Возможности читалки

- Русский интерфейс, адаптивное меню, оглавление страницы, поиск и тёмная тема.
- Переходы между разделами и постоянные ссылки на заголовки.
- Закладки на текущий раздел, удаление закладок и продолжение чтения.
- Закладки и последняя позиция сохраняются локально в браузере; синхронизации между телефоном и компьютером нет.

## Запуск

Нужен Node.js 20 или новее.

```sh
npm ci
npm run dev
```

Сборка: `npm run build`. Просмотр сборки: `npm run preview`.

При размещении в подпапке GitHub Pages установить `SITE_BASE=/cortex-ru/` перед сборкой. По умолчанию используется `/` для локального просмотра и размещения в корне домена.

## Структура

- `book/` — сайт и текст перевода.
- `book/chapters/` — переведённые главы после получения оригинала.
- `book/glossary.md` — согласованный глоссарий.
- `translation/` — карта глав, вопросы и редакторские решения.
- `sources/` — предоставленная английская книга и русский PDF-лист (оба добавлены по указанию пользователя).

Репозиторий первоначально был приватным; 17.10.2026 пользователь прямо поручил открыть его и опубликовать сайт. Лицензия VitePress не распространяется на книгу и её перевод.

Интерактивный лист: `book/character-sheet.md`; оригинал и доработка v1 находятся в `book/public/sheets/`. Статус проверки — `translation/character-sheet.md`.
